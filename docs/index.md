# Welcome

Welcome to Roman Mendoza's documentation site, built with
[Zensical](https://zensical.org/).

## Getting started

Add Markdown pages to the `docs/` directory and list them in the `nav` section
of `zensical.toml` to include them in the site navigation.

See the [Zensical documentation](https://zensical.org/docs/) for authoring guides
and configuration options.
